A [make.fun](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) entry for the **One-Liner Laugh Lab** bounty: write one short funny line answering a prompt — here, the excuse a robot vacuum gives after eating a sock.

`main.ts` (Node 22) writes exactly one line, at most 200 characters, to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: two runs produce byte-identical output. No network, no input files.

Run it:

```sh
node main.ts
```
